# AI Digital Employee — Project Coding Instructions

## Tech Stack
- Python 3.12+ (FastAPI, Pydantic v2, AsyncIO, SQLite WAL)
- TypeScript + React (Workbench Console)

## Coding Standards
- Commit messages must use Conventional Commits in English (`feat:`, `fix:`, `refactor:`, `test:`).
- Python identifiers use `snake_case`; classes use `PascalCase`.
- Respect repository `.ai/DECISIONS.yaml` policies and `TaskContract.permitted_scopes`.
- Every bug fix must be accompanied by a deterministic `Fail-to-Pass` regression test.
